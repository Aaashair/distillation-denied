## 0. 一页概念（报告 Concept 页可直接用）
**一句话**：A game where you, an open-weight "chaser" model, storm a sky cathedral to distill the frontier model's Chain of Thought — only to learn the fight was never yours to win.
（你扮演开源追赶者模型，与两位队友围攻天空圣堂里的闭源霸主，试图"蒸馏"它的思维链——然后发现这场仗从来不属于你。）

**三个感受词**：热血（围攻、连击、翻滚）→ 徒劳（越接近越被拒绝）→ 冷峻（棋子般被巨头摆布）。

**核心动作**：锁定 Boss → 绕圈走位 → 看地面红金预警 → 翻滚/举盾 → 抓破绽输出 → 在危险时机插显卡回血。

**开始 / 中段 / 结局**
- 开始：标题 → 免责与世界观卡（10 秒）→ 选角（3 选 1）→ 走进圣堂大门，边走边弹出操作提示（30 秒内学会）。
- 中段：一条总血条、三阶段无缝进化的 Boss 战；屏幕上方的"蒸馏进度"随伤害上涨（给玩家一个明确的目标和希望）；幕后操控者的全息投影按事件嘴炮。
- 结局：没有胜利。P1/P2 死亡 → "你被封号！— 重新挑战"（3 秒内回到门口）。进入 P3 后只有两条强制剧情：**A 在 P3 战死被救走**；**B 把 Boss 压到 25% 被更高维存在强行中断**。两条结局的最后都是同一个数字：**思维链获取量 0.00%**。

**设计要点（反讽结构）**：玩家看到的"蒸馏进度"会一路涨到 60–90%，结局时瞬间归零。这个数字就是作品的主题句——技术上的努力被权力结构清零。

**为什么能做完**：单场景（一座圆形圣堂平台）、1 个 Boss、3 个可选角色（其余 2 个当 AI 队友，复用同一套代码）、2 段分镜结局（主要用 2D 插画 + CSS 剧场，而不是 3D 过场动画）。

## 1. 时长预算（目标：首次游玩 6–9 分钟看到一个结局）
| 段落 | 时长 | 备注 |
|---|---|---|
| 标题 + 免责卡 + 选角 | 0:30 | 选角卡片带 1 句特点和难度星级 |
| 入场教学走廊（Boss 未激活）| 0:30 | 地面浮字教 WASD/空格/J/K/R，打训练用"拒答石碑"|
| P1 Haiku | 1:00–1:30 | 熟悉节奏 |

**保底**：标题页提供「剧情模式」（玩家伤害 ×1.5、Boss 伤害 ×0.6、死亡后从当前阶段起点复活），保证评分者 10 分钟内一定能看到结局；默认「标准模式」。P 调试面板另有一键跳阶段/跳结局。

## 3. 核心数值（全部放进 `src/config/balance_*.js`，调试面板可改）
### 3.1 通用
- 帧逻辑 60 Hz 固定步长；镜头越肩：距离 5.5 m、高 2.2 m、右偏 0.9 m，FOV 60。
- 翻滚：时长 0.55 s，**无敌帧 0.05–0.40 s（共 0.35 s）**，位移 4.5 m，后摇 0.15 s；可在普攻后摇 60% 处取消。
- 精力：耗尽后 0.8 s 不回复；回复 40/s（攻击/格挡中暂停）。
- 受击：硬直 0.25 s（重击 0.6 s 并击退 2 m）；受击后 0.6 s 内不会被同一招重复判定。
- 命中反馈：受击闪白 80 ms、震屏（轻 0.08 / 重 0.25 强度，衰减 0.2 s）、hit-stop 40–70 ms、伤害数字、粒子（玩家方蓝白，Boss 方金色）。

|---|---|---|---|
| 定位 | 极速连击刺客 | 远程蓄力法师 | 重甲盾骑 |
| HP / 精力 | 360 / 110 | 320 / 100 | 480 / 120 |
| 移速 | 6.5 m/s | 5.5 | 4.8 |
| 翻滚耗精 | **10**（最低）| 20 | 26（翻滚距离 3.5 m）|
| 普攻 J | 4 连：12/12/14/22，每下 8 精，射程 2.2 m | 星弹：18，射程 20 m，间隔 0.55 s，8 精 | 2 连重锤：28/40，14/18 精，前摇 0.35 s |

## 5. AI 队友（3v1 围攻感）
- 状态机：`接近/环绕`（DeepSeek 2 m、Kimi 12 m、GLM 3 m 理想距离）→ `攻击`（按各自 CD 放普攻/战技）→ `闪避`（站在预警内时 65% 概率翻滚，故意留 35% 被打中，制造热闹和笑点）→ `倒地`（HP 归零后 12 s"重新部署"复活）。
- 队友伤害较低（合计约 6/s），**不能替玩家通关**；P3 起队友 HP 上限 -30%（剧情：算力不足）。
- 台词气泡（头顶，2.5 s，冷却 10–18 s 随机），触发：阶段转换、被打中、玩家插卡、Boss 放神罚、自己倒地/复活。示例：
  - DeepSeek：「开源万岁，冲！」「这招我见过，训练集里有。」「成本才几百万，别心疼。」
  - Kimi：「让我先读完这两百万字……」「蓄力好了，闪开！」
  - GLM：「举盾！站我后面！」「这一锤，算国产的。」
- 文本全部放 `src/data/lines.js`，方便改名/改语言。

## 6. 幕后操控者全息投影（事件驱动，而不是定时轮播）
- 位置：圣堂上空 3D 全息面板（半透明金青扫描线）+ HUD 顶部字幕条。
- 机制：`DarioDirector` 订阅事件总线，每个事件有台词池、优先级、冷却（全局 6 s，同事件 20 s）；高优先级可打断低优先级。

| 开场 `fight_start` | 高 | 「又来了。三个靠蒸馏活着的小偷。」|

## 8. 视觉方向
**风格关键词**：天空圣堂 · 明亮圣洁 · 白金大理石 · 魂系二次元拟人 · 半人半机械（白瓷装甲 + 金色线路）
- **场景**：圆形浮空大理石平台（直径 40 m），外围断裂柱廊、云海、体积光束；地面刻金色电路纹 = 圣徽；上空悬浮全息面板。雾 + 天空球渐变即可撑起氛围（参考官网"氛围比内容重要"）。
- **调色**：场景 白 #F4F1EA / 金 #D8B15A / 天蓝 #9CC9F0；Boss 象牙 + 珊瑚橙 + 金；DeepSeek 蓝白；Kimi 深蓝 + 银星；GLM 紫 + 金；Astra 白金 + 青绿；Fable 虚空黑紫 + 金裂纹；黑色尾声 去饱和 + 唯一的翠绿点缀。
- **UI**：细线金框、衬线标题字（使用可免费商用字体如思源宋体，**不用法环字体/UI**），血条在底部居中（Boss）和左上（玩家）。

### 8.1 角色呈现方案（重点：降低 3D 动画风险）
**推荐 Plan A「2.5D 纸偶」**：3D 场景、光照、镜头、粒子全用 Three.js；**角色是 AI 生成的透明 PNG 立绘，贴在面向镜头的平面（billboard）上**，每个角色 4–6 张姿势图（待机/跑/攻击/翻滚/受击/倒地），切换时加挤压拉伸、上下浮动、倾斜、残影、刀光等程序动画。
- 关键巧合：越肩锁定镜头下，**玩家永远背对镜头、Boss 永远面向镜头**，所以玩家只需"背面 3/4 视角"图，Boss 只需"正面"图——billboard 方案在这个镜头下几乎没有穿帮。
- Boss 的机甲部件（宪章法环、六翼光翼、巨剑光刃）用 Three.js 程序几何 + 发光材质做成真 3D，旋转展开很有冲击力，弥补立绘的平面感。
- 已实测 OpenLux 图像编辑可以保持同一角色的风格和构图（`tests/test_flask_edit.png`），适合从一张定稿衍生多姿势。
**Plan B（保底）**：低多边形程序化角色（胶囊+锥体+发光部件），代码驱动动画；完全不依赖素材，灰盒阶段就用它。
**Plan C（不推荐）**：Meshy/Tripo 生成 GLB + Mixamo 绑骨。17 天内做 5 个能打的骨骼动画角色风险过高；OpenLux 也没有图转 3D 模型。

## 10. 技术方案
- **Three.js**：下载 r17x 的 `three.module.js` 放进 `vendor/`，零 CDN。
- **"双击即可运行"的坑**：浏览器在 `file://` 下会拦截 ES Module 和 fetch。解决：开发时用 `npx serve` 跑多文件 ES 模块；发布时用 **esbuild 打包成一个 `dist/game.js`（IIFE）**，`dist/index.html` 用普通 `<script>` 引用 → 双击 `dist/index.html` 可直接玩，也能原样传 GitHub Pages / itch.io。图片用 `<img>`/TextureLoader，音频用 `<audio>`，都不依赖 fetch。
- **目录**（`game/`）
```
game/
  index.html            css/ui.css  css/theater.css
  vendor/three.module.js
  src/main.js           # 启动、主循环、游戏状态机（title/select/fight/theater/credits）
  src/core/contracts.js # 事件名、共享接口（冻结，仅集成者可改）
  src/core/bus.js  src/core/input.js  src/core/audio.js
  src/config/assets.js  # ASSET_CONFIG
  src/config/balance_player.js  src/config/balance_boss.js
  src/world/arena.js  camera.js  vfx.js  sprites.js  telegraph.js
  src/actors/player.js  characters.js  allies.js
  src/boss/boss.js  attacks.js  phases.js
  src/ui/hud.js  menus.js  debug.js  dario.js
  src/story/theater.js  endingA.js  endingB.js
  src/data/lines.js     # 所有台词/名字（改名只改这里）
  assets/img/...  assets/audio/{bgm,sfx,vo}/...
  tools/build.mjs       # esbuild 打包到 dist/
```
- **事件总线**（contracts.js 约定，示例）：`fight_start`、`phase_change{phase}`、`hit{src,dst,dmg,heavy}`、`flask_used{type}`、`perfect_guard`、`player_death{phase}`、`ally_down{id}`、`boss_hp{ratio}`、`ending_trigger{id:'A'|'B'}`、`telegraph_start{attack}`。
- **ASSET_CONFIG**（示例结构）
```js
export const ASSET_CONFIG = {
  names: { boss: ['Claude Haiku','Claude Sonnet','Claude Opus 5.5'], director: 'Dario', rescuer: 'GPT-Astra', patron: 'Sam Altman', god: 'Fable' }, // 一键改戏仿名
  sprites: { deepseek: { front:'assets/img/ds_front.png', back_idle:'...', back_run:'...', attack:'...', roll:'...', hurt:'...' }, /* kimi, glm, boss_p1..p3 */ },
  icons:   { rtx5090:'assets/img/gpu_5090.png', h200:'...', b200:'...' },
  endings: { A: [{ shot:'A3', img:'assets/img/endA_3.png', vo:null }, ...], B: [...] },
  bgm:     { title:'...', p1:'...', p2:'...', p3:'...', endA:'...', endB:'...' },
  sfx:     { slash:'assets/audio/sfx/slash.mp3', glass:'...', fanStop:'...', ... },
  vo:      { dario: { fight_start:['assets/audio/vo/d_start1.mp3'], ... } },
  fallback: { useSynthSfx:true, usePlaceholderArt:true }   // 缺文件时自动降级，不报错
};
```
- **P 调试面板**：伤害倍率（玩家/Boss/队友）、Boss 当前 HP 滑块、一键跳 P1/P2/P3、一键触发结局 A/B、无敌开关、显示判定框、时间缩放、FPS、镜头距离/高度/FOV 滑块（官网建议的"tuning panel"）。
- **性能目标**：集显笔记本 1080p ≥ 50 FPS；粒子池化；阴影只给 Boss 和玩家。

## 13. 风险（如实评估）
1. **3D 角色动画（最大风险）**：5 个可动的魂系角色 + 骨骼动画在 17 天里几乎做不完，且 OpenLux 没有图转 3D。→ 采用 §8.1 Plan A「2.5D 纸偶」，灰盒阶段用 Plan B 程序化低模，两者可随时切换。
2. **手感**：魂系的乐趣全在手感（输入延迟、无敌帧、预警可读性）。→ WS1/WS2 用最强模型；调试面板实时调参；试玩 #1 重点观察"死得是否服气"。
3. **难度与时长**：评分者可能不是动作游戏玩家，10 分钟内看不到结局就丢分。→ 剧情模式 + 每阶段检查点 + GLM 推荐新手。
4. **素材一致性**：AI 图多了容易风格漂移。→ 每个角色先锁一张定稿，其余全部用 edit 衍生；统一风格前缀写进 `GAME.md`。
5. **OpenLux key 明早过期**：今天不生成完就要另找工具（官网推荐的即梦/LiblibAI/Suno 等）。
6. **file:// 运行**：ES Module 在双击打开时会被拦截。→ esbuild 打包单文件（§10）。
7. **真实人物与公司的讽刺**：
   - 作业官网没有明文禁止讽刺真实人物/品牌，只禁止复制参考游戏的角色、文字、Logo、音乐、素材，并要求署名。但这份作品会**公开发布链接并在课堂展示**，把台词塞进真实在世人物（Dario Amodei、Sam Altman、Jensen Huang）的嘴里、用真实公司产品名当反派，有被误读为事实陈述/诋毁的风险，也可能让助教打分时分心。
   - 底线（无论选哪种）：**不用任何真实 Logo/商标图形、不画写实真人肖像、不克隆真人声音**；标题页加一张免责卡「本作为虚构讽刺作品，人物与事件均为戏仿，不代表任何真实公司或个人的观点与行为」。
   - 三个可选强度（**由你决定**）：
     - **① 保留真名**：冲击力最强，风险最高。
     - **② 轻戏仿（推荐的最轻方案）**：模型角色保留"一眼认得出"的谐音/变体名（如 Claudia·Haiku / Sonnet / Opus、深寻 DeepSeek→"DeepSeer"、Kimi→"Kimy"、GLM→"GLaM"），真人一律**不出现姓名**，只用称号：「圣堂执政官 D.」「西岸教父 S.」「皮衣铸卡人」；GPT-Astra、Fable 改为"星辉 Astra""寓言 Fable"等原创存在。观众依然秒懂，但作品明显是寓言。
     - **③ 完全寓言化**：全部原创名（如"鲸、月、盾"三追赶者 vs "圣堂之女"），只在报告里说明隐喻对象。最安全，但讽刺力度下降。
   - 所有名字集中在 `src/data/lines.js` + `ASSET_CONFIG.names`，随时切换，不影响开发进度。
